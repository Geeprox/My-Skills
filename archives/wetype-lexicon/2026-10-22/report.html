原生学习记录

个人学习词典把拼音、文字和学习元数据关联保存。原生 Add 同时维护记录、索引与同步动作；重复已有词对时直接跳过，保留其原有频率。

重新启动仍能召回

添加副本与验证副本分开。新进程按完整拼音查候选，避免候选曝光统计混入待提交数据；新增词对缺失、审核或召回失败时不提交该批。

官方同步继续工作

每段操作结束后恢复官方输入法，让其正常消费新增动作。工具不伪造确认、不裁剪队列、不重置累计序号。

有状态的批量任务

完整词表规范化后存为签名任务。每批重新查重、检查队列并记录事务。队列繁忙、网络未恢复或进程中断时，原任务保留剩余词表。

固定版本的原生适配与旧词保护

普通初始化保持原有 KV 编码。沙箱 worker 只在一次原生 Add 及其任务等待期间，临时控制已定位的词典实例运行标志，避免附带旧词清理；完成后恢复。完整主记录、旧元数据、逻辑 KV、连续新 action 和累计头均严格审核。这是已逆向的内部适配，不是官方公开批量 API；正式 App 恢复正常运行配置。

正式操作使用 launchd 服务互锁与独立 guardian，核对无官方进程、源文件清单和期限后才交换。异常恢复先阻止原协调器继续提交，再恢复服务。重启可能保留启动限制；recover-service 在原生编译及版本检查之前可执行。

使用 Skill

提供 word 与 pinyin；每词1–16个汉字，逐字对应不带声调的合法音节。多音字读法由用户确定。明确要求导入日常词库时，Skill 沿正式目标完成以下流程。

wetype-sync --target formal --workspace 私有路径/wetype-lab-import init
wetype-sync --target formal --workspace 私有路径/wetype-lab-import prepare words.csv
wetype-sync --target formal --workspace 私有路径/wetype-lab-import preview --job importjob-ID
wetype-sync --target formal --workspace 私有路径/wetype-lab-import run --job importjob-ID
# 队列繁忙，继续使用同一任务
wetype-sync --target formal --workspace 私有路径/wetype-lab-import resume --job importjob-ID

任务、备份、审计密钥与完整词库留在私有工作区。每段最多500条，待处理动作窗口为900；显式等待可设0–900秒，退出后不后台续写。

REA 在研究中做了什么

REA 提供可追溯的逆向工作流和局部反编译线索，帮助定位学习、序列化和锁路径。原始 Mach-O 的符号与局部汇编确认具体 ABI、动作分配和清理条件；隔离原生程序验证实际变化；接收端核对验证真实跨设备到达。

这几层证据各自回答不同问题。3.0 全应用 Ghidra 分析没有完成；局部结果由原始指令和运行实验交叉核对。REA 没有替代云端观察，普通使用此 Skill 也无需安装 REA。
