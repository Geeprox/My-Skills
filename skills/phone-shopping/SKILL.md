# 操作手机挑选采购商品

根据当前用户需求筛选商品，交付具体 SKU、平台/店铺、显示到手价、推荐理由和待决策项。面向通用品类；不预设特定任务、个人资料、品牌或设备偏好。付款和下单由用户人工完成。

## 先准备能力与平台

- 先读 [能力选型与自动安装](references/bootstrap.md)。复用已安装且可用的手机控制能力；缺失时根据当前主机、连接设备和可访问发布自动选型、安装依赖/MCP、配置并验收，不能只给用户安装步骤便停止。仅安装当前设备所需能力，不为只有一种手机的用户安装两套。
- 解锁、账号登录、信任、开发者模式与系统授权需要本人完成时，说明具体阻塞和步骤，等待实际完成，继续不依赖该步骤的工作。遵守宿主安装和权限要求，不能绕过。
- 发现已安装电商 App 与当前可用账号。淘宝/京东按任务范围比对；**所有可用手机均未安装山姆时跳过山姆**，记录“未安装，未比较”，不自动安装山姆或为它阻塞任务。一台已安装时可在该台读取，不要求每台安装。安装目录查询失败不等于未安装，先按包标识/实际安装证据复核；安装但无法访问则另记原因。
- 多设备用 [动态分工](references/long-running.md)：按可用 App、账号、当前进度和任务成本分配独立候选/调研队列，执行中可调整。设备不固定绑定平台，不预设 iPhone 或 Android 必然更优；同台手机串行操作，跨设备在工具支持时并行。

## 商品挑选流程

1. **明确需求。** 从本次对话整理用途、预算、数量、硬约束和必要兼容性，按实际任务建立分类。仅追问会影响选型的缺失信息；个人尺寸等只有本任务确需时才询问，留在私有任务台账，不写入 Skill 或公开仓库。
2. **先扩展候选池。** 用标准搜索引擎及小红书、抖音、微博搜索品类推荐、对比和实际体验，见 [调研与选型](references/selection.md)。**手机已安装小红书时优先操作 App** 搜索并进入结果研究；不可用或未安装时用可访问网页/搜索引擎，不自动装社交 App。商单/广告可提供线索，不自动排除，也不能当独立验证。
3. **跨品牌、SPU/SKU 与店铺筛选。** 将推荐线索转为可核对的型号/规格，再进电商商详比较。**优先品牌官方旗舰店、平台旗舰店或可核实的自营官方渠道**，同时综合到手价、补贴、配置和店铺可信度；不为“旗舰”标签忽略明显价差，也不把京东物流等同自营。
4. **读取商详并核对同款。** 选中所需 SKU/数量后读取价格、关键参数、适用限制、包装/配件与必要图片。参考 [淘宝](references/taobao.md)、[京东](references/jd.md)，仅在山姆可用时读 [山姆](references/sams-club.md)。按 [采集协议](references/capture.md) 保留覆盖与断点；必要信息读完可略过底部通用免责声明，商品专属脚注仍读，避免进入无限推荐流。
5. **比较显示到手价与适配性。** 按 [比价规则](references/selection.md) 比较同款所选 SKU 的到手价、补贴到手价、补贴后、入会价、优惠后/券后价，保留必要条件、数量、时间。不同配置分开比较，跨品牌比较适配与取舍，不以最低价替代选型。
6. **补缺、加购与分类。** 商详缺少决定性信息时按 [客服与购物车](references/customer-cart.md) 询问该店客服；任务范围允许时加购首选及待取舍候选，标明二选一/多选一。按当前平台实际支持能力整理本任务购物车分组，保留原有条目。结果未知先回读，不重发或重复加购。
7. **交付。** 简单任务直接给结论；多品类或取舍复杂时生成 [决策文档](assets/selection-task-template.md)，逐项列明具体商品/SKU、各平台可比价、官方店铺核验、推荐与备选理由、参考资料、客服答复、加购/分类状态及用户下一步。

## 操作范围与效率

本 Skill 支持必要商品客服确认、普通商品优惠券领取、加购与分类；实际执行遵从当次用户任务及宿主权限，只要求调研时不扩展购物车或消息操作。编辑/安装 Skill 本身不启动选购或发送消息。付款、下单、退款由用户人工操作。

默认按平台已显示的优惠价比较，不研究或购买付费会员，不例行向客服确认运费、退货邮费、保修或付款环节。若用户接受先买后试用，可列在家试用取舍；不将门店试装作为前置条件。页面明确费用/试用限制时记录例外，不自行保证所有商品免费退回；当次用户另有要求则遵从。

通过 [设备操作](references/device-operation.md) 使用当前观察定位。稳定可读列表用原生树，图片正文用截图，转场/异常同时取两者。低密度场景图略读，参数、配件、兼容性和脚注细读，不能把未读图片默认当装饰。

复杂任务按 [长任务留档与恢复](references/long-running.md) 持久保存候选、来源、客服与操作状态，设备暂离可转移独立工作。用户要求定时进度时使用指定间隔，未指定可用 15 分钟；没有常驻能力不承诺离线运行。

`scripts/summarize_observation.py` 只压缩兼容 PUA 快照，不自动识别同款/优惠条件或决定停止。`scripts/record_event.py` 只写本地事件与断点，不能保证平台动作幂等。未付款只能报告显示到手价/预期实付。验证边界见 [验证说明](references/validation.md)；任务数据、地址、身份、设备标识、通知、账号和付款资料不进入 Skill 或公开仓库。
