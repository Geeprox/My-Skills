# 京东布局与操作

按当前 App/账号/SKU 观察使用以下线索，不照搬旧坐标、商品或版本。

## 搜索与列表

- 包标识线索：iPhone `com.360buy.jdmobile`；Android `com.jingdong.app.mall`。中文别名查询空结果时，按包标识或英文片段核对，不误判未安装。
- 首页热词轮换；旧 label 可失效。截图确认无弹窗后定位真实输入区域，聚焦再输入并精确回读，提交后等卡片加载。
- PUA Android 曾暴露首页 `com.jingdong.app.mall:id/b2q`、搜索页 `com.jd.lib.search.feature:id/zs`、提交 `com.jd.lib.search.feature:id/yw`；搜索框可能没有标准 class。只有所选 adapter 确实支持该当前控件时使用；不将旧 ID 或作者本地适配当通用能力。标准聚焦字段可按工具说明省略 selector。
- 卡片混排广告、普通店铺、京东物流与自营。优先核对官方/平台旗舰身份；京东物流不等于自营。
- 聚合卡片可为 iPhone Other、Android ViewGroup/content_desc，标题可能有零宽字符；使用真实完整卡片关联价、条件、销量与店铺。不同账号排序不同，不能按第几条匹配。

## 商详、目录与停止

- 常见固定导航“商品／大家评／详情／推荐”；固定推荐按钮不代表正文已结束。
- 图文目录可能包含活动专区、商品介绍、规格参数、服务。iPhone 行可能为 Cell + StaticText，按真实节点消歧。
- 目录跳转可能有动画、白屏或保留旧树；先确认落点。直播浮窗/提示会遮挡，只关已观察的关闭入口。
- 参数表有“展开”时，关闭目录浮层，把入口滚到真实可操作区。点击后核对新增字段、表格高度或“收起”；树保留隐藏字段不能替代展开确认。
- 包装/服务后可能为价格说明 → 看了又看。完整模式可在正文收尾与独立推荐卡片交界停止；挑选模式必要信息读完后可以跳过通用价格说明。当前商品优惠、版本、适用限制的小字仍核对。
- 配送节点可能带完整地址、门店精确距离；仅记录任务相关服务与时效，不将个人地址或距离写入可分发 Skill/报告。
