# 手机观察与操作

先按能力选型参考准备并验收当前 provider。PUA 同名工具按 iphone_use/android_use 命名空间区分；其他 provider 按实际 schema 映射，不套用 PUA 字段。工具未热加载可用安装项目提供的 Runtime/CLI。沿已验收通道确认解锁和前台；解锁、登录由用户完成。

## 从搜索到商详

- 首页搜索占位热词会轮换，使用当前稳定控件/resource-id。输入后精确回读，再提交；结果页先等待商品卡片出现，不能把接受点击当作加载成功。
- 精确型号搜索没有匹配时，可改用品牌、花色、尺寸或版本词寻找候选，再进入商详核型号。一次空结果不证明全平台无货或停售；近似图片/名称也不证明同款。
- 保持商品卡片、价格条件、店铺、广告/自营标记的位置关联。淘宝付款人数、京东已售量和浏览人数分别记录。同标题、价格或列表序号不证明同商品/同 SKU。
- 商详选中目标 SKU 后重新观察标题、版本、价格和包装。弹窗、直播浮窗遮挡时只处理已观察的关闭入口。
- 完整正文路径是概览 → 评价/店铺等中段 → 图文详情 → 说明/正文收尾 → 末尾推荐。挑选任务必要信息读完后可在底部通用免责声明前停止，记录跳过；不强制走到推荐入口。分区导航可能仍在动画/加载中，先确认落点。每次单次手势，保留约 25–40% 的正文重叠，保存新标题、续段、小字和断点；边界判据见 [采集协议](capture.md)。

## 减少观察与恢复成本

首次进入、弹窗、异常、阶段转换取 both；稳定可读列表用 tree；纯图片正文用 screenshot。预览直播帧供用户观看，不算模型已读取证据。没有新 native 文字并不代表图片正文没移动。

PUA Android 使用 content_desc/text/resource_id/class_name，PUA iPhone 使用 label/name/value/type；其他 provider 按当前 schema 的真实字段定位。可见按钮可能实际为 StaticText/Other，使用当前真实类型。selector 不唯一先检查候选，用区别明确的完整卡片/标题；不要尝试一串猜测 selector。

树可能包含屏外或折叠内容。点击前检查 rect、可操作区域、中心位置和覆盖层。存在“展开”不证明能点；展开后回读表格是否真正改变。原生定位报遮挡而截图确认无浮层、入口可见时，可按当前截图使用一次坐标动作。

按 provider 说明使用坐标；PUA Android 为 display pixels、iPhone 为 points，截图坐标乘其 pixel_to_display / pixel_to_point；其他 provider 不沿用该换算。滚动区域排除固定搜索栏、分区导航、购买栏和浮窗。

滚动返回 no_scroll_progress 时先看截图：锚点可能不可读或移出区域。确认真正移动可继续当前阶段；未动则检查区域、弹窗或加载，不能把校验失败当全文结束。图片正文依据相邻截图判断进度，不强求文字锚点。连接超时先恢复读取，不重放结果未知的点击、输入、加购或消息。

不使用 collect_list 自动扫完整商详，以免进入无限推荐流。已保存快照可用 summarize_observation.py 提取可见卡片和导航；它不证明同款、完整覆盖或最终价格。保留定位需要的原始证据，交付去掉地址、通知、搜索历史和付款资料。

多设备暂离和跨天恢复按 [长任务留档](long-running.md) 保存独立断点、未决副作用和队列，不把短暂断联当任务取消。

Android已安装App查询的中文别名覆盖可能有限：例如淘宝中文查询空列表，按包ID片段`taobao`实际可返回`com.taobao.taobao`。空别名查询不等于未安装；按已知平台包ID/英文片段核验`installed_verified`，仍无结果再按实际界面查找。目录/安装证明与登录、当前账号、会员和地区配送环境分别记录，切设备后重新核对后者。
