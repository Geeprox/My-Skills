# 手机操作能力选型与自动安装

## 复用与选择

先盘点宿主可调用手机工具、已注册 MCP/插件、真实设备和主机系统。已有通道先读其使用/setup 文档并验证，不为了统一名称重新安装。同名工具按服务命名空间分开；模拟器、设备在线、服务端口可达或包已安装均不等于真机可操作。

缺失能力时自动选择本地真实设备方案：以实际 OS/机型兼容、中文输入与回读、页面树/截图、明确设备绑定、可恢复动作和安装维护成本为依据。已有一个健康方案便复用，避免为这项任务重复横评。需要用户主机未支持的 iPhone 构建时不假定命令行工具等于完整 Xcode；可先使用已有可用设备推进。

候选与官方来源：

- [iPhone Use](https://github.com/zhongerxin/iPhone-use)：macOS 上已有或可取得时，按当前 README/安装脚本安装本地插件，使用其 setup 获取/签名/构建/启动 WDA，验 `pua_ready`。需要用户自己的 Apple 开发团队和签名配置，不能复制作者值。
- Android Use：若当前宿主目录中有可访问、版本与依赖可验证的正式安装包，按其 setup/install 文档准备 ADB、独立 Python 环境、UI Automator 和可选预览。不能假定本 Skill 附带 Android 插件，不能将某作者的本地加固版或未合并 PR 当通用正式发布。
- [Mobile Next Mobile MCP](https://github.com/mobile-next/mobile-mcp)：公开的跨平台候选，提供真实设备发现、App、元素/截图与输入操作；无法取得专用插件时可选择。按当前官方 README 和真实设备指南检查依赖与系统兼容；公开包可安装不证明当前机型已验收。接口不是 `pua_*`，按实际工具 schema 适配。

来源或版本不可取得时换可访问方案，不索要作者私有目录、不使用虚构下载链接。选择只需解释与本机有关的理由，不编造“更快、更安全、更省 Token”的比较。

## 自动执行安装

1. 用宿主插件搜索/安装能力（若支持）或已安装 CLI 检查当前配置；来源选正式目录、维护者仓库/包注册表。获取当前 README、release/包版本、依赖和实际安装脚本，记录版本或 commit；不要直接执行未知网页片段。
2. 在宿主允许的任务/应用数据目录保存依赖与源码。自动补齐当前方案所需依赖，采用独立环境，不覆盖已有 MCP 配置、证书、账号或其他工具服务。只配置所需平台，USB 为默认连接；不默认启用无认证无线调试、root 或云端账号。
3. iPhone Use 使用所获取源码的 `sh scripts/install.sh`；具备已验证来源的 Android Use 使用该发布随附的 `sh scripts/install_android.sh`。先读脚本和平台条件，不将两条命令套在不含它们的版本上。
4. 选择 Mobile MCP 时从官方 npm 包元数据解析兼容的正式版本并固定，先检查 `codex mcp add --help`（其他宿主用相应配置 API）。Codex 的注册形态可为：

   ```sh
   codex mcp add mobile-mcp --env MOBILEMCP_DISABLE_TELEMETRY=1 -- npx -y @mobilenext/mobile-mcp@<已核实版本>
   ```

   尖括号是待解析版本，不能原样执行；不要长期以 `@latest` 隐式升级。注册前查同名服务，已健康则不覆盖。其他宿主按其 MCP 配置文档处理，不假定有 Codex CLI。
5. 复用已配置设备与活动初始化 job，缺失服务才启动一次，按 job 查询；需要锁屏解除、USB 信任、开发者模式、Apple 登录或系统权限时提示用户在设备完成，等待实际回复。选择安装与例行依赖准备不额外设置统一批准关卡；确需宿主授权时按准确阻塞请求，不绕过。
6. 新服务没热加载时先尝试宿主支持的重连；可用的项目 CLI/Runtime 能继续验收则继续。否则保存配置与断点，说明需要重连，不伪称工具已就绪。包注册成功、工具加载、设备连接、服务启动与实际控制分别报告。

## 真机验收与能力映射

PUA 方案：首次 `pua_setup(action="status")`，复用健康服务/活动 job，缺服务时 start，再 `pua_ready`，只有 ready=true 允许操作。按 provider setup 文档发现/选择真实设备；不要为每件商品重复整套诊断。

其他 MCP：按工具列表发现真实设备并绑定其实际标识，读取前台、屏幕尺寸、截图/元素；必要时在无提交的搜索字段输入并精确回读。没有 ready 接口不伪造 ready=true，记录完成的同等操作证明。能力映射至少包括 App 安装查询/启动、观察、点击、滑动、完整中文输入；预览若支持则打开并复用，预览缺失不等于控制失效。

恢复只处理失效层，不整套重装。密码/验证码/Face ID 接管期间按所选 provider 暂停预览及操作，用户完成后新观察恢复。设备标识、Team、签名、账号、日志与截图只留私有运行目录，不进入可分发 Skill。这里规定自动安装流程，不承诺每个 OS/手机无需本人确认，也不授权安装山姆或小红书 App。
