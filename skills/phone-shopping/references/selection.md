# 商品挑选与跨平台比价

## 两种比较不能混为一谈

**同款比较**回答在哪里买更便宜。核对品牌、官方型号/货号、代次/版本、规格、颜色（价格相关时）、容量、套装配件、数量、全新/二手/翻新状态。两个平台的商品 ID 本来可能不同；用官方型号与选中 SKU 的配置建立对应，不要求跨平台 ID 相同。只有标题相似或同属一个 SPU，不足以判为同款。不确定时写“疑似同款，待确认”。

**跨品牌/SPU/SKU 比较**回答哪个更适合需求。先排除硬约束不符项，再比较关键体验、兼容性、体积/重量、配件与总体成本；说明推荐理由和替代款的取舍。不要把不同品牌/版本按最低价直接排名，也不要用任意综合评分制造精度。多店铺同款优先品牌官方旗舰店、平台旗舰店或可核实的官方自营渠道，并检查主体、商品状态、关键差评和型号一致性。名称带“官方”“旗舰”、品牌广告或物流标记不能单独证明官方身份；按平台标记、店铺主体/品牌授权等当前证据核对。综合到手价、补贴、配置与可信度，显著价差需说明；非官方店铺可作为价格参考或有依据的备选，明确推荐取舍。销售数与宣传不替代证据。

候选采集采用两轮：列表筛选 → 有竞争力的候选商详读取。优先填补证据缺口、找同款另一平台报价和真正不同的方案；当新增候选无法改变推荐/取舍时停止，不无限浏览推荐流。保留淘汰原因摘要，避免反复打开已排除商品。

## 显示到手价口径

- 主比较价为当前选中 SKU、所需数量实际显示的 **到手价、补贴到手价、补贴后、入会价、优惠后、券后价** 等。保留页面原标签与金额，不用划线价、原价、优惠前价代替。列表价用于初筛，商详选 SKU 后再确认。
- 不研究平台付费会员、不摊销会员费、不询问客服会员权益。显示的入会价可以参与比较，若页面有待入会/待领券等必要动作则注明当前状态；不把付费订阅当作可自动执行的步骤。
- 不把换新抵扣、回收预估、分期每期价、定金、未来返现或另一个 SKU 的最低起价混作当前普通购买价。正常显示的补贴、券或支付专享价可以记录；只保留页面确实出现的条件，无需额外追问用户支付方式或向客服验证付款环节。
- 明确普通可获得价与有条件显示价。例如“京东 ¥X（补贴到手价，页面注明京东支付专享）；淘宝 ¥Y（补贴后）”，结论为“按当前显示价京东便宜 ¥Δ，条件见表”。已失效、账号不可领取或选中 SKU 不适用的价，不算已可获得价。
- 比较相同需求数量：总价、件数/容量和单价同时记录。不能将每件价与一套价比较；计算金额使用十进制精度。配置不同则先分组，不为了同款比较随意给赠品估价。必要配件另购时列出已知总成本；未知配件价写缺口。
- 不例行向客服研究运费/保修；用户约定包邮、免费退回时作为本任务默认。页面若明确额外费用或特殊不可退/试用限制，只记录该例外及影响，不默认为通用保障，也不主动扩大客服问题。
- 优惠是否需要操作，要分清“显示报价”“可领取/已领取”“购物车显示价”。可在选品范围领取该商品普通优惠券；付费会员或收费权益由用户决定。不同口径暂不一致时记录冲突，回到对应 SKU/优惠节点核对，不编算一个最低数字。
- 加购前刷新已选 SKU 的报价；标记观察日期时间。购物车价格变化时更新文档。没有人工付款，就写“显示到手价/预期实付”，不是支付完成证明；无需为了比价生成订单。

## 比价最小记录

每个候选一行，至少保留：

```
需求项/系统；品牌/SPU；选中 SKU 与数量；平台/店铺；商品 ID/链接（能取得时）
匹配状态 exact|different_configuration|uncertain；匹配依据
显示到手金额；价格标签原文；单位/套装；必要条件及已验证状态；观察时间
决定性参数与来源；缺失字段；客服确认；推荐/备选/淘汰理由
加购状态；平台分组；需用户决策内容
```

跨平台报价取自当时 App 页面，不把历史测试价格当当前价格。研究通用技术参数或产品比较时可补充官网/说明书等资料，给出链接与适用型号；价格仍以当前 App 选中 SKU 为准。商品宣传、客服回答、用户评价和独立资料分别标明，不把广告说法升级为实测结果。

## 选购前扩展候选池

先用标准搜索引擎和小红书、抖音、微博搜索品类推荐、对比、使用体验和常见问题，提取品牌/SPU/型号以及待核事实；任务规模小或已有明确型号时做有界补查，不无限收集榜单。除非用户限制来源，推荐信息调研属于选品流程，无需为普通公开搜索重复询问。

手机已安装小红书时优先进入 App，搜索后打开有价值的结果读取正文/图文与必要评论；用 App 安装查询核实，不以搜索别名无结果判未装。多台手机中选择可用的一台。未安装、登录阻塞或结果不可访问时改用可访问网页/搜索引擎，并标明范围；不自动安装社交 App、不把搜索摘要称为完整阅读。抖音、微博按实际可用渠道读取；视频仅取得链接、读取转录、实际播放三种状态分别记录。

广告/商单通常也有参考价值，可用于扩展候选池；标注已知合作关系，未知则写未知，不从口吻推定，也不因带货自动排除。提取卖点后回到商详、官方资料或必要客服核对。转载、同源榜单和重复视频不算多份独立证据。

记录来源链接、作者/机构、发布日期（能取得时）、读取时间、具体型号/版本、实际读取范围，以及影响哪个候选。体验结论不自动泛化到其他代次；宣传百分比、认证、规格与性能排名不能只凭广告或评论定论。来源不可用则记录缺口并继续，不为社会证明阻塞选购。

## 通用参数与配置核验

按当前用途核对相关参数，区分外尺寸/可用尺寸、整机/部件、净重/含包装重量、静态测试值/正常使用限额、设备支持/随箱配件支持、当前模式/另一模式参数。推算值注明依据和假设，不能写成已核实。只收集本任务确需的个人适配信息，不从历史任务带入个人身高、年龄、住址或家庭背景。

混合 SPU 商详中参数表和图片可能属于不同版本，应对准选中 SKU。正文展示的配件不一定随基础 SKU 附送，核对包装清单与选配脚注，分列基础价及必需配件总成本。证书、手册和客服回答必须匹配当前型号、地区版本和配置；安装空间、手感等适配可按用户接受的在家试用方案列核对点，但不能用试用替代关键规格事实。

## 购物车限时价过期

购物车可能保留旧金额，同时明确显示限时补贴/折扣已失效。旧车价只作历史；重新打开同条商品的只读规格，核对相同 SKU、数量和当前优惠条件，分别保存新商详价与旧车价。不能为刷新价格重复加购或生成订单，也不能把最低起价替代所选套餐。结论采用最近有效证据。
