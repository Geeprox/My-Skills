# 淘宝布局与操作

以下为可复用布局观察，不是永久界面契约；使用当前节点/截图确认，不沿用旧商品或坐标。

## 搜索与列表

- 包标识线索：Android `com.taobao.taobao`，iPhone `com.taobao.taobao4iphone`；用实际安装查询核对。
- 首页可能恢复上次页面，先用当前可见首页入口；搜索热词会轮换，不把占位词当长期 selector。
- PUA Android 搜索字段曾暴露 `com.taobao.taobao:id/searchEdit` / EditText，提交为 `com.taobao.taobao:id/searchbtn` / Button；iPhone 可见 SearchField。按当前 schema/焦点输入并精确回读，接口变化不盲猜。
- 列表含广告、排序、分类、补贴与店铺横条。聚合卡片常在 Android content_desc/View、iPhone label/Other；价格条件、店铺和券标签可能分离，按卡片位置关联。
- 品类搜索可能混入其他型号；官方旗舰身份与当前 SKU 需要独立核实，物流/付款人数不等于官方店铺或性能证明。

## 商详与正文边界

常见顺序：主图/价格 → 当前购买方式 → 标题 → 配送/服务 → 参数/SKU → 评价/店铺 → 中段商品推荐 → 宝贝详情 → 图文正文/说明 → 末尾推荐。实际模块可变化。

- 固定“宝贝／评价／详情”导航可能是 TextView/StaticText，不硬编码 Button。
- 中段“商品推荐”可能在“宝贝详情”前，不能据此判断正文结束。详情跳转等待真实落点再读取。
- 长图可能无可读原生正文，即使树只剩导航/购买栏，截图仍包含参数、比较表、包装与脚注；切换视觉读取。
- 摘要参数可能不完整，分别记录正文、参数表和 SKU 来源；存在矛盾不擅自覆盖。
- 普通购买、组合、换新预估和选配不是同一价格场景；保留显示优惠标签与原文条件。

## 操作异常

弹窗可遮挡搜索入口；节点存在不等于可操作。滚动锚点只读 text 时可能漏 content_desc 卡片；锚点移出区域也可能误报无进度。先看截图确认实际移动，图文正文依赖视觉进度。不要把未移动、树无新文字或底栏截断当已读完；无可靠末尾证据则标 partial。选品必要信息读完可按采集协议跳过通用免责声明，完整读取任务保留其未覆盖区块。
