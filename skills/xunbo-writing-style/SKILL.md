# Xunbo Writing Style

用于用户明确要求的个人风格写作、改写和压缩。写当前用户提供的事，遵守当前请求的立场、用途和篇幅。

## 先读原话

写之前读 [原话节录](references/xunbo_posts.md)。按任务选择短帖、思考或技术段落来校准，保留对整段节奏的感受，不逐句拆成可拼装的模板。

样本比风格分析更重要。下面的概括只用于提醒，不能反过来把原文修成符合概括的样子。仿写时不照抄样本的句子。

## 把握语气

- 像在和熟人讲自己刚看到、遇到或想到的事。让人看得懂事情为什么让你有话要说。
- 可以认真展开推理，也可以只说两句。长度随事情走；用户指定篇幅时以用户要求为准。
- 联想常常来自工程、物理、语言、产品或流行文化。联系要有实际内容；当前素材没有合适的联想，就把事情讲清楚。
- 可以有括号、反问、英文词、表情和不太整齐的短行。它们各有语境，不按清单逐项添加。
- 幽默可以来自字面理解、词序交换、谐音、一本正经地胡说或临时自我拆台。也允许一篇从头到尾认真，不额外制造笑点。
- 说完就停。结尾可以继续推理、留下疑问、突然收短或落在一个具体细节，不规定反转、升华或价值总结。

## 写与改

1. 从当前素材确定真正想说的内容。改稿优先保留有辨识度的原句、措辞和停顿，不把它们统一润色成顺滑的书面语。
2. 直接选择自然的形式；不先套模板，不要求每篇完整走过“观察—类比—反思”。
3. 写完回看：有没有额外编出一次自我发现、硬塞比方，或在已经说完以后又讲一段道理？删去没有素材支撑的部分。
4. 区分表达习惯和事实可靠性。新文不照搬旧样本的错误、刻板印象或未经核实的强结论；类比不能替代机制证据。

除非用户要求分析，直接交付文案。不自动复制剪贴板、发布或发送。

## 配图与样本边界

配图、视频可能参与笑点和意思。先看用户给的素材；画面已交代的内容可以留给画面。看不到关键素材时，不补造现场。

公开节录只选不含个人背景的部分，保留了原话；完整核证材料不随 Skill 发布。不要把当前任务中的私人素材自动加入公开样本。样本中的人称与情节不能当成当前用户的新经历。

作者发布、引用和 AI 共创需要区分。优先用可辨认的个人表达校准自然语感；用户认可过一段 AI 文字，不代表它就是其独立写作的首要范本。不编造经历、情绪、朋友评价、数据、引文或引用出处。
