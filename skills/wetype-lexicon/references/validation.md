# 兼容与验证边界

- 平台：Apple Silicon macOS；实测系统 macOS 27.0.1。
- 应用：微信输入法 3.0.0（670）。
- Universal 主程序 SHA256：`ba19f0c2783acb8c6f09cf2c9d95e55a33bbc93034ef3d97ab728021cdda14a8`。
- ARM64 切片 SHA256：`861d0b7f61d6f666745aadfc3073b156e972be87d67ba71919938406b82adebb`。
- `scripts/engine_support.py` 校验应用、模型与框架依赖，并核对派生 bundle 的文件段未改动。升级后停止执行，不把版本号相同当作兼容。

## 已验证与尚未验证

2026-10-17 工具源代码完成26项真实隔离端到端检查、38项纯逻辑审核测试，以及3项真实隔离词条/模拟应用恢复失败检查。500词整批添加、新进程全量召回和审核约103秒，包含原有词记录未变的核对。该数字是单机历史结果，不是每台机器的速度保证。

先前另有一个虚构测试词经明确授权写入正式词库，重启后回读通过，并在官方输入法中逐键全拼+Space实际上屏。这不代表新版 Skill 已对其他用户、版本或正式大批词表完成测试。

历史规模实验在固定合成分布上：1万词全部新进程召回；2万词全部词对存在，但候选只抽样1000；5万词样本999/1000成功，失败事务未提交，后续31次对照未复现原因。未找到可推广的统一引擎硬上限，不能把500条工具批次限制或5万实验失败写成引擎容量。

候选只枚举前2048项：找到目标即通过，并保留是否截断；目标未找到则拒绝提交，不能断言词在更后面也不存在。仅验证连续全拼；云同步、双拼、简拼、混输、断电耐久性和全部评分规则未完成验证。

## 审核约束

原生 worker 在加载微信输入法代码前启用沙箱，拒绝直接读取/写入正式词库、作业外写入和联网。每个事务复用私有 HMAC key，对比全量主词记录及元数据，精确核对每个新增词对和已跳过词对。

完整逻辑 KV 差异只允许目标拼音桶、连续原生 action 与精确递增的日志头；已有拼音桶可因新增同音词而修改。header累计计数不能用当前剩余action最大键替代。只Add的提交副本不执行候选查询；另一个新进程副本负责召回，避免曝光统计污染。

协调器正常退出官方输入法，持有与LevelDB一致的POSIX fcntl记录锁，备份完整v5及SHA256清单，再同文件系统RENAME_SWAP交换。不能通过打开后关闭同一个LOCK inode做哈希而释放记录锁，因此复制和哈希使用已持有的fd。

隔离回滚恢复整个快照并核对主词记录冲突。2026-10-19 已在隔离库复现：模拟清理日志但不改主词后，旧正式回滚保护仍允许序号回退并复用；故1.1禁用正式导入与快照回滚，保留隔离行为。recover根据已审核前后记录摘要分类并恢复输入法状态，不代表对所有可能损坏状态进行自动修复。

## 复测入口

`python3 "$SKILL_DIR/scripts/audit_tests.py"` 是纯逻辑审核；`python3 "$SKILL_DIR/scripts/selftest.py" --workspace /私有路径/wetype-lab-selftest-唯一名称` 使用新隔离库和真实原生代码；`scripts/lifecycle_tests.py` 使用隔离真实词条并模拟应用恢复故障。不要在正式词库运行故障注入。

REA是本次研究使用的工作流和静态证据入口；3.0全量Ghidra分析未成功取得可用记录；2026-10-19 对精确提取的584字节ARM64序列化函数，通过REA/Ghidra取得伪代码，与原产物指令互证。该小片段不等于全应用分析成功。3.0 ABI由安装产物的符号与指令审查、隔离harness和运行验收补证。普通使用无需安装REA。归档报告保留成功和失败证据边界。

## 同步核查更新（2026-10-19）

参见 [同步兼容性](synchronization.md)。1000 是消费者按累计序号减本地水位计算的保留窗口，256是一次读取上限；每批500输入行并不保证多批或已有积压不会触发裁剪。本地原生Add写入同步操作日志，不等于账号具备上传条件、服务器已接受或其他设备已合并。源设备选词后的远端命中会混入正常学习，不能作为纯导入成功的因果证据。
